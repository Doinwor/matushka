# Матушка

Национальный музыкальный плеер: «Моя волна», артисты и их треки.
Мобильный веб-сайт на чистом HTML/CSS/JS, без сборки и сервера.
Хостинг — GitHub Pages, все данные и музыка лежат файлами в репозитории.

## Что уже есть

- Главная страница: блок **«Моя волна»** — случайные треки всех артистов без остановки.
- Список артистов с поиском.
- Страница артиста: фото-заглушка, жанр, описание, список треков.
- Нижний плеер: играть/пауза, следующий/предыдущий трек, перемотка.
- Музыка не прерывается при переходе между экранами.
- Поддержка экрана блокировки (Media Session API).
- Мобильная вёрстка, тёмная тема с триколором.
- Демо-артисты и три демо-трека для проверки.

## Запуск локально

Нужен Python 3 (уже установлен):

```bash
python tools/serve.py
```

Откроется `http://127.0.0.1:5500/`. Остановить — `Ctrl+C`.

Просто открыть `index.html` двойным кликом нельзя: браузер не даст загрузить
`data/library.json` и модули JS с `file://`. Поэтому нужен локальный сервер.

## Структура

```
index.html                 оболочка сайта (SPA)
css/style.css              всё оформление
js/app.js                  экраны, роутер, поиск, «Волна»
js/player.js               плеер и очередь треков
js/data.js                 загрузка и нормализация library.json
data/library.json          ВСЯ информация: артисты и треки
audio/<артист>/<трек>.mp3  музыка
audio/demo/*.wav           демо-треки (потом удалить)
img/icon.svg               иконка сайта
manifest.webmanifest       установка на телефон
tools/serve.py             локальный сервер
tools/make_demo_audio.py   генератор демо-треков
tools/mobile-preview.html  предпросмотр в рамке телефона
```

## Как добавить артиста и треки

Открой `data/library.json` и добавь артиста в массив `artists`:

```json
{
  "id": "ivanov",
  "name": "Иван Иванов",
  "genre": "Фолк",
  "bio": "Коротко об артисте",
  "photo": "img/artists/ivanov.jpg",
  "tracks": [
    {
      "id": "ivanov-01",
      "title": "Берёзы",
      "album": "Дом у реки",
      "src": "audio/ivanov/beryozy.mp3",
      "duration": 214,
      "year": 2026,
      "cover": "img/covers/beryozy.jpg"
    }
  ]
}
```

Правила:

- `id` артиста и трека — уникальные, латиницей, без пробелов;
- `src` — путь к mp3 от корня сайта;
- `duration` — длительность в секундах (для списка треков);
- `photo` и `cover` можно не указывать — тогда рисуется красивая
  градиентная заглушка автоматически;
- если поля нет или оно `null`, сайт не сломается.

Файлы кладутся в `audio/<id-артиста>/`, картинки — в `img/artists/`
и `img/covers/`.

## Ограничения GitHub

- один файл — до 100 МБ;
- весь сайт — около 1 ГБ (лучше держаться до 500 МБ);
- mp3 128–192 kbps: примерно 3–5 МБ на трек;
- Git LFS для GitHub Pages не работает — обычные файлы в репозитории.

## Публикация на GitHub Pages

1. Создать репозиторий (например `matushka`).
2. Загрузить файлы в ветку `main`.
3. В настройках репозитория: **Settings → Pages → Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
4. Сайт будет доступен по адресу `https://<username>.github.io/matushka/`.

После каждой правки `library.json` сайт обновляется автоматически.
Чтобы браузер не показывал старую версию данных, сайт запрашивает JSON
с меткой времени.
